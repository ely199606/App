# Manzanín

Aplicación Android de AppSchooling con perfiles locales, hábitos de estudio y una bandeja de avisos para las familias.

La compilación de GitHub Actions genera una APK release sin firmar. La clave privada de firma se conserva fuera de este repositorio.

Proyecto Android: Java 17, Gradle 8.9, Android SDK 35. La recepción de comunicaciones utiliza Firebase Cloud Messaging y permiso de notificaciones.
